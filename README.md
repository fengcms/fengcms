# FengCMS

FengCMS 是一套使用 PHP 和 MySQL 的开源内容管理系统，适合搭建文章、产品等展示型网站。系统支持自定义内容模型、字段和模板，可用同一后台管理不同类型的内容。

**当前正式版：v1.36。** 请从 [GitHub Releases](https://github.com/fengcms/fengcms/releases) 下载正式版本和校验文件。系统不提供在线升级；已有网站应先备份，并在副本中完成升级验证。

## 主要功能

- 自定义内容模型和字段，管理文章、产品等内容。
- 管理栏目、内容、留言、图片和附件。
- 使用 wangEditor 5 编辑正文，可上传图片、选择站内资源或插入网络图片。
- 使用模板控制网站展示，保留原有模板变量写法。
- 后台提供超级管理员和编辑两种账号角色。

## 系统要求

当前安装说明面向 PHP 8.3 或 8.4，并要求 `mysqli`、`mbstring`、`gd`、`fileinfo` 和 `json` 扩展。数据库使用 MySQL 或 MariaDB。具体 Web 服务器要求、数据库权限和写入目录见[新站安装指南](docs/安装指南.md)。
