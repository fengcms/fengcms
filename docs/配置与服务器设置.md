# 配置与服务器设置

## 私有配置

安装器会在站点根目录生成私有 `config.php`。它只保存配置数据，不应包含程序逻辑。该文件含数据库凭证、后台认证码和应用密钥：

- 不要提交到 Git、发到公开论坛或放到可公开下载的位置。
- 限制文件读取权限，仅让 PHP 运行用户和受信任的系统管理员访问。
- 更换配置前，先在副本验证数据库连接和后台登录。
- `config.example.php` 只用于查看配置格式，不可当作正式凭证使用。

容器部署可通过环境变量提供配置。若同时使用环境变量和私有配置，程序按环境变量优先的规则读取。旧站点配置迁移说明请先阅读[升级指南](已有网站升级指南.md)。

## Web 服务器配置

当前发布包附带以下配置文件：

| 服务器 | 使用的配置 | 配置要求 |
| --- | --- | --- |
| Apache | 根目录 `.htaccess` | 启用 `mod_rewrite`，并允许站点目录使用重写规则。 |
| Nginx | 由管理员配置 | 将请求交给 `index.php`，并阻止访问私有目录、配置/备份文件和上传脚本。仓库中的 Nginx 配置是本地容器示例，生产环境需按实际路径和 PHP-FPM 地址调整。 |
| IIS | 根目录 `web.config` | 安装 IIS URL Rewrite，并配置 PHP FastCGI。先在目标 IIS 版本的副本中验证。 |

根目录 `httpd.ini` 面向旧版第三方 ISAPI_Rewrite 模块，供仍依赖该模块的历史站点参考；当前 IIS 部署应使用 `web.config`。根目录 `nginx.conf` 是旧示例，本地 Docker 当前使用 `docker/nginx/default.conf`。

## 部署后检查

从浏览器逐项确认：

- 首页、文章、栏目、标签搜索、留言等站点路由正常。
- 私有配置、安装 SQL、程序源码目录和备份文件不能直接下载。
- 上传目录内的 PHP、HTML、SVG、SHTML 和 JS 文件不能被访问或执行。
- 后台登录、图片上传、资源选择及模板显示正常。
- IIS 站点确认已启用 URL Rewrite；Nginx 站点确认访问限制已经由管理员配置。

静态检查配置文件不能代替真实 Web 服务器验证。若主机面板不允许配置访问限制，请联系主机商，不要通过开放目录权限绕过限制。
