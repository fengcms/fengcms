# 常见问题

## 安装页面打不开或显示 404

安装向导只用于全新站点，并要求发布包中有 `install/index.php`。已安装站点和本地开发容器会主动关闭该入口。检查 URL Rewrite/伪静态规则、PHP FastCGI 及主机面板的站点根目录设置；不要在已有数据库上重复安装。

## 安装停在环境检查或数据库连接失败

确认 PHP 为受支持版本并启用安装指南列出的扩展；核对数据库主机、名称、用户名、密码和权限。数据库需要由主机面板提前创建。详细准备步骤见[安装指南](安装指南.md)。

## 后台无法登录

确认账号、密码和认证码填写正确，检查键盘大小写及输入法。后台认证码不是验证码图片，也不等同于第二个密码。连续失败后可能触发登录限速；稍后再试，并检查 PHP 错误日志和站点会话目录权限。

若账号已被停用、删除或重置凭据，请联系超级管理员。不要在公开问题中发送密码、认证码或配置文件。

## 伪静态页面 404

Apache 需要启用 `mod_rewrite` 并允许 `.htaccess`；Nginx 需要管理员配置前端入口和访问限制；IIS 需要安装 URL Rewrite。确认规则加载在正确的网站根目录，并在 Web 服务器副本验证。详细说明见[配置与服务器设置](配置与服务器设置.md)。

## 图片上传提示文件内容不允许

系统会综合检查扩展名、实际 MIME 类型、文件大小和图片是否可解码。请尝试从图像软件重新导出为 JPG、PNG、GIF 或 WebP 中主机支持的格式，避免只修改文件扩展名。确认上传没有超过主机限制；必要时请管理员检查 PHP 上传临时目录和 `upload/` 写权限。

## 图片上传成功但页面不显示

检查资源 URL 是否可访问、图片是否被浏览器或 CDN 拦截，以及模板引用是否正确。网络图片由浏览器访问远程地址，图片来源可能禁止外链或已删除。

## 后台数据库导入失败

检查备份是否由 FengCMS 生成、目标库表结构是否与备份一致、文件大小与记录数是否在限制内，以及数据库用户是否具备所需权限。大数据库或跨版本恢复请在隔离副本使用主机数据库工具，不要反复尝试不匹配的备份。出现“中断恢复”提示时，按[数据库备份与恢复](数据库备份与恢复.md)处理。

## 我可以在后台自动升级吗？

不能。后台只查询 GitHub 上的最新正式版本并提供发布页面入口，不会下载或覆盖站点代码。请按[已有网站升级指南](已有网站升级指南.md)手动升级。

## 仍无法解决

记录 FengCMS 版本、PHP/数据库/Web 服务器版本、操作步骤和不含敏感数据的错误信息，到 [GitHub Issues](https://github.com/fengcms/fengcms/issues) 提交问题。不要附带数据库、私有配置、密码、认证码、用户个人信息或线上备份。
