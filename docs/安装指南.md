# 新站安装指南

本向导只用于**全新网站首次安装**。已有 FengCMS 网站不能用它覆盖升级；已有网站请按[升级指南](已有网站升级指南.md)操作。网页安装器从 v1.36 起提供。

## 一、准备主机与数据库

1. 在主机面板启用 HTTPS，选择 PHP 8.3、8.4 或 8.5，并启用 `mysqli`、`mbstring`、`gd`、`fileinfo`、`json` 扩展。
2. 在面板创建 MySQL 或 MariaDB 数据库及专用数据库用户。该用户需要对目标数据库建表、建视图和写入数据的权限。
3. 将正式发布包解压到网站根目录。Apache/LiteSpeed 需允许 `.htaccess` 生效；Nginx 需由管理员配置访问规则；IIS 需安装 URL Rewrite 并配置 PHP FastCGI。细节见[配置与服务器设置](配置与服务器设置.md)。
4. 确认 PHP 运行用户可以写入站点根目录的私有 `config.php`，以及 `upload/`、`app/cache/`、`admin/app/cache/`、`admin/app/dbbackup/`、`var/runtime/`。只授予必要权限，**不要使用 777**。
5. 确认数据库用户权限适合网站日常使用。后台备份需要读取数据和锁表；后台导入还需要建表、重命名表和删除表权限。

## 二、设置一次性安装授权

通过主机文件管理器或 SFTP，将 `install/authorize.example.php` 复制为 `install/authorize.php`。生成 32 至 128 位随机密钥，只使用英文字母、数字、下划线和短横线，并替换文件中的示例占位符：

```php
<?php
return '替换成你自己生成的随机密钥';
```

该密钥只用于首次安装，不是后台密码。不要将它提交到 Git 或公开发送。

## 三、在浏览器中安装

1. 打开 `https://你的域名/install/index.php`，输入一次性安装密钥。
2. 等待环境检查通过，填写数据库连接信息、**未使用的表前缀**、管理员用户名和密码。管理员密码至少 12 字节、至多 72 字节。
3. 在确认页面核对数据库名称、表前缀以及将创建的数据库对象。确认无误后再开始安装。
4. 安装完成后保存页面显示的后台认证码，并访问 `/admin/login.php` 登录。
5. 检查前台、后台、图片上传及模板功能；确认 `install/authorize.php` 已删除，再次访问安装入口应被拒绝。

安装器会生成私有配置、应用密钥和管理员认证码，不会删除已有数据库表。若安装中断，不要对同一个表前缀直接重试：先查看数据库中本次创建的对象，恢复干净状态或改用全新数据库和前缀。

## 四、安装后检查

- 确认首页和后台均可打开，管理员可正常登录。
- 上传一张常见格式的图片，检查资源列表和前台显示。
- 在后台创建数据库备份并下载，妥善保管备份文件。
- 确认私有配置和安装 SQL 不能通过浏览器下载，上传目录中的脚本不能执行。
- 把数据库信息、后台认证码、私有配置备份和恢复步骤保存在安全位置。

安装问题可先查看[常见问题](常见问题.md)。配置文件和服务器规则见[配置与服务器设置](配置与服务器设置.md)。
