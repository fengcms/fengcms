# 后台数字参数与结果跳转检查

检查日期：2026-10-26。范围为仓库现有后台异步保存回调、结果页和 `id`/`classid` 的数字参数入口。它是针对同类错误的检查，不等于全系统安全审计。

| 入口 | 原因与处理 | 验证 |
| --- | --- | --- |
| 留言回复 | 保存层丢失原 ID，实际更新成功后返回空 ID；返回真实 ID，重复保存也成功。结果页无需单条 ID。 | 独立测试留言的浏览器提交与数据库回归。 |
| 自定义模型系统字段、回收站还原 | 批量接口没有单条 ID，旧回调拼入 `undefined`；统一跳转时省略 ID。 | 批量业务回归、结果页和回调检查。 |
| 模型导入、报名设置 | 响应不提供单条 ID；统一跳转时省略 ID。 | 回调与无 ID 结果页检查；未执行真实模型导入和报名业务保存。 |
| 文章、栏目、模型、自定义字段保存 | 失败响应可不含 ID；仅合法单条 ID 被加到地址，结果页仅在记录存在时显示编辑链接。 | 成功/失败回调组合、无 ID 和有效 ID 结果页检查。 |
| 栏目根排序 | 旧链接输出空 `classid`；改为 `0`。 | 根列表链接和排序页 HTTP 检查。 |
| 栏目及字段排序 | 正常 `id[]` 被单值守卫误拒；只对对应 POST 接口开放逐项校验，先检查全部 ID 是否存在，再更新。 | 正常/重复/异常数组、CSRF、缺失记录不部分更新的业务回归。 |
| 自定义字段新建 | 建列使用未定义的模型属性；改用实际字段模型并校验模型、字段名及类型，返回新 ID。 | 临时模型中真实建列、元数据与重复保存回归。 |

验证命令：`./bin/dev check`（333 个 PHP 文件语法通过）、`./bin/dev test`（268 项业务回归及 9 项数据库驱动回归）、`node tests/navigation-regression.js`（312 组真实后台回调的成功/失败及 ID 组合）、`git diff --check`。截图保存在忽略目录 `var/verification/message-reply-fixed.jpg`。测试只在带 `f_dev_meta` 标记的开发数据库运行；临时留言、账号和回归数据完成后清理。

尚未在本地执行模型导入、报名业务保存的完整流程；开发库缺少对应报名表，模型导入也可能执行外部 SQL。相应入口已验证不会再把缺失 ID 拼入结果 URL，但业务功能仍需在专门的预发布数据副本上验收。存量站点的 PHP 版本和定制代码须先核对，不能直接部署本分支。
