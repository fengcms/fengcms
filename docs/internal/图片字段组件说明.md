# 后台图片字段缩略图组件

2026-10-29，按已确认方案实施。调整后台编辑体验，不迁移数据库、不修改前台模板或模板调用语法。

## 接入与兼容

`admin/js/image-fields.js` 在编辑器适配器启动时扫描带 `data-cms-kind="image"`、`data-cms-target` 的原资源选择按钮。接入单图、通用自定义图片、多图等既有表单，不依赖字段必须叫 img 或 zoompic。新组件脚本由现有十处后台编辑表单统一加载；附件与模板选择按钮不受影响。批量添加模板已加载组件，若当前批量页面不输出图片字段，则无额外界面。

原 input 保留名称、ID、datatype、校验信息与表单提交能力，视觉上隐藏；旧选择按钮隐藏。没有加载新组件时仍显示原输入框和选择按钮。初次挂载不规范化或改写原值，包含多图尾部逗号和历史重复分隔符。明确调整顺序、移除或确认资源选择后，按既有单图地址、多图逗号分隔并保留尾逗号的格式回填，触发 change 刷新缩略图。原表单的必填、长度等校验继续存在。

资源选择器继续带入全部已有引用；添加图片不直接覆盖整个数组。重复选择的行为沿用资源选择器的选中/取消机制。新增可见按钮不复用 `data-cms-target`，避免与编辑器全局点击代理重复打开弹窗。资源选择器允许调用方传入 restoreFocus，关闭后回到重新渲染后的可见入口；附件、模板原调用继续返回原按钮。

## 显示、预览和排序

单图和多图使用相同尺寸缩略图，桌面 112px，窄屏 88px。多图末尾保留等尺寸添加入口，空间不足换行。操作栏始终可见，适合触屏；支持同一字段内拖动及左右按钮排序，不跨字段移动。

站内上传图片优先使用既有认证缩略图接口；历史其他 HTTP/HTTPS 地址由浏览器直接显示，不新增服务器远程下载。拒绝 javascript/data/file、协议相对地址、凭据网址、反斜杠和控制字符等不支持的预览地址，但保留原值并显示占位，不因预览失败清空数据。使用 DOM 属性与 textContent 渲染地址和提示，不拼接 HTML。

预览为原生 dialog，支持上一张、下一张、方向键、Esc、关闭按钮和背景关闭，关闭后恢复焦点。图片按需加载，错误时显示原地址。移除只解除内容引用，不删除服务器资源；排序、选择和移除仍须保存当前表单。
