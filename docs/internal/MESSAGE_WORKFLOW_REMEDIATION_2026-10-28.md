# 留言工作流审阅修复

依据[审阅报告](MESSAGE_WORKFLOW_REVIEW_2026-10-28.md)处理 LM01–LM06。

## 修改

- **LM01 公开边界：**前台列表、总数和分页统一按 `status=1` 查询。后台将状态明确显示为“待审核（不公开）”和“已发布（公开）”；回复内容不再隐式决定公开状态。
- **LM04 回复保存：**移除对整份 POST 的旧标签替换。只接受明确字段，验证字符串类型和长度，保留空值、`0`、URL、斜线、换行、引号及普通文本；模板原有默认转义继续负责输出安全。管理员可以清空回复并设置待审核。失败时页面保留编辑内容并显示错误。
- **LM02 并发编辑：**回复表单携带 HMAC 编辑基线，数据库行增加随机 `edit_version`。写入在留言行命名锁内校验基线，并用包含旧行值的条件 UPDATE 防止检查与更新分离。旧表单返回 409；同值保存仍成功；记录在等待更新时被删除则返回 404。
- **LM03 可续做批量删除：**先验证并去重完整 ID 列表，再逐项执行并返回 `changed`、`already`、`failed`、`unprocessed`。批次等待总预算为 12 秒，单条数据库锁等待设为 2 秒。中途失败后原 ID 列表可重试；已删除记录作为 `already` 跳过，继续处理剩余项。页面显示逐项结果并保留选择。
- **LM05 同次提交恢复：**每张留言表单有绑定当前会话的随机提交标识，最多保留 20 张、有效 30 分钟。留言行唯一 `submission_key` 将同次表单绑定到已保存记录；重试返回原 ID，不重复插入。验证码只在新建前验证，SQL 插入失败时不消费，成功或结果恢复时消费。新表单允许提交相同内容。
- **LM06 提交确认：**确认框移到 Validform 的 `beforeSubmit`。取消不会发起保存；成功回调提示留言等待审核；验证码、字段和网络错误不跳离表单。

## 数据库升级

新安装 SQL 包含 `submission_key`、`edit_version` 和提交标识唯一索引。已有站点需先备份数据库，再运行 `php tools/migrate.php`；迁移可重复执行。无法运行 CLI 的虚拟主机可按[安装升级说明](INSTALLATION.md)在数据库管理工具执行等价变更。旧留言记录的两个新字段保持 `NULL`，首次编辑按当前行建立基线，不改写历史正文。
