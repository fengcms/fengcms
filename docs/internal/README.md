# 内部维护与审阅资料

本目录保存开发记录、安全/性能审阅、修复复盘、历史说明和发布流程，供项目维护者追溯。报告中的代码行号、测试数量和阶段性结论只适用于其记录的时间点，不能当作当前用户操作手册。

这些资料继续保存在 Git 中，但通过根目录 `.gitattributes` 的 `export-ignore` 规则从 Git 源码归档和发布附件中排除。仓库访客从 `.github/README.md` 了解项目；下载发布包的用户从根目录的 `项目说明.md` 和[中文使用文档索引](../README.md)开始。根目录 `README.md` 用作 GitHub 个人主页介绍，不进入发布包。

旧 Windows 文档保存在 [`legacy/`](legacy/)，仅作为历史参考，不代表当前版本的安装、升级或安全建议。
