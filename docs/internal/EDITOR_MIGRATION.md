## 网络图片入口（2026-10-26）

工具栏“图片”菜单现在提供“上传图片”和“网络图片”。选择“网络图片”后填写完整 HTTP/HTTPS 图片地址，可填写图片描述及点击图片后的跳转链接，然后点击“确定”。保存文章后外链仍作为 HTML 图片地址存储，由访问者浏览器直接加载，服务器不下载或转存远程文件；远端防盗链、失效和 HTTPS 页面的混合内容限制仍可能影响展示，建议使用 HTTPS 图片。

通过 wangEditor 原生 `insertImage`、`editImage` 配置启用并校验网址，参考 [官方菜单配置](https://www.wangeditor.com/v5/menu-config.html#图片)。拒绝危险协议、带用户名密码的网址、反斜杠和控制字符；编辑已上传图片时允许原有站内绝对路径。图片跳转链接也校验协议。服务端 HTML Purifier 白名单继续生效。

工具栏和分组按钮异步生成，适配层监听其生成并补充可访问名称，编辑器销毁时清理监听器。

验证：`node tests/editor-regression.js` 覆盖网络图片地址、危险协议、跳转链接、已有图片兼容、菜单入口和正文同步；`./bin/dev test` 共 116 项通过，新增 HTTP/HTTPS 图片保存、带查询参数的网址编辑回显及前台输出检查；332 个 PHP 文件语法检查通过。真实浏览器验证后台 iframe 中图片分组、插入绝对 HTTP 地址、保存、重新打开以及图片加载成功；该图片使用本地另一主机名模拟外链，不代表所有第三方图床可用。测试账号和文章已清理，截图存于忽略目录 `var/verification/`。

## 使用、维护和回退

- 刷新后台即可使用新编辑器。常用文字样式、列表、链接、表格、图片、撤销重做和全屏可用；无任意源码/iframe/脚本/视频嵌入功能。
- 图片/附件单文件上限 10MB，单个富文本字段上限 2MB；支持的文件类型以 admin/api/upload.php 为准。上传进行中阻止保存，避免正文引用未完成上传的资源。
- 动态新增的富文本字段由 type_quote 元数据识别，保存时自动清洗；前台仍使用原变量语法。普通 textarea、标题和摘要不会当作可信 HTML。
- wangEditor MIT 许可与 HTML Purifier LGPL 许可分别保留；无需商业授权。vendor 目录是部署必需源码，纳入 Git；下载缓存与验证截图位于已忽略的 var。
- 本地 Nginx 配置同步变更为仅执行新 API。未来 Apache/Nginx 生产部署必须配置等效规则，不能仅拷贝 JS。
- 代码回退点为各阶段提交；如需完整回到迁移前，先备份当前改动，再在独立分支/预发布检出迁移前版本。已重新保存的 HTML 不会随代码回退恢复，需使用内容备份。
- 本次未部署线上、未转换历史文章。选择 wangEditor 5 不等于完成所有 CMS 安全审计，仍需持续关注依赖漏洞和项目维护状态。
