# 后台模板写入的安全边界

FengCMS 模板会编译为 PHP，模板表达式也可调用 PHP 函数。因此，拥有后台在线模板写入权限的超级管理员实际上拥有服务器代码执行能力。只扫描 `<?php` 等字样不能可靠地消除这项能力；对现有模板语言做完整沙箱会改变已部署站点的模板行为。

需要在线维护模板的站点可以保留此功能，并应严格保护超级管理员账号、限制人数、监控私有 PHP 日志。模板保存与删除成功时，日志会记录管理员 ID、模板分类和文件名，不记录模板正文。

不需要在线维护模板的站点，可在**服务器私有环境配置**中设置 `FENGCMS_DISABLE_TEMPLATE_WRITE=1`。后台仍可查看模板列表和源码，保存、创建及删除会返回 403；模板文件仍可经受控部署流程更新。开发环境默认保持可写，以运行模板管理回归。

这一开关只控制后台模板管理入口。部署时仍应限制源码目录写权限、保护管理员凭据，并在站点副本核查定制模板。它不负责检查已有模板中的代码，也不替代隔离发布与审计。
