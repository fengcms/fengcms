# 后台授权 AUTH01 修复记录

日期：2026-10-28。对应审阅：[后台权限边界与对象级授权审阅](ADMIN_AUTHORIZATION_REVIEW_2026-10-28.md)。

## 修复内容

- 编辑角色读取栏目列表和排序列表时，先验证指定父栏目属于其可管理范围；根级请求保留原入口。受限栏目作为父级时返回 403，不再允许通过枚举其子级读取元数据。
- 栏目列表、排序列表及栏目选择树只向编辑返回可管理栏目。允许范围为启用的内容模型栏目、单页栏目，以及属于启用内容模型或公共范围的外链栏目；系统模型和停用模型栏目不返回。
- `classify` 选择路由省略模型参数时仍兼容后台原调用，但结果会经过相同的编辑角色范围过滤。显式请求未授权模型仍返回 403。
- 超级管理员的读取结果不经编辑角色过滤，保持原有可见范围。

## 回归覆盖

`tests/regression.php` 增加编辑及超级管理员 HTTP 会话用例，覆盖根列表、根排序、允许父级下的列表/排序、受限父级拒绝、缺省及指定模型的栏目选择，以及超级管理员结果保持完整。授权用例的栏目夹具使用独立清理数组，不改变既有排序测试所依赖的夹具顺序。
