# 资源选择器界面调整与验收记录

范围：图片选择、批量图片、附件和模板选择。方案经确认后已于 2026-10-26 在本地开发环境实现。下文保留设计范围，并记录实现与验证结果。

## 统一交互框架

采用与后台协调的蓝灰配色、白色内容区、统一圆角与间距，弱化旧式按钮堆叠。桌面弹窗建议约 900×620，受视口宽高限制；小屏改为接近全屏。顶部固定标题和关闭按钮，中间为可滚动内容区，底部固定取消/确认。提供 Esc 关闭、焦点留在弹窗内、关闭后返回触发按钮。

## 图片选择

分为“资源库”和“上传图片”两个页签。资源库默认缩略图网格，可切换列表；每张图展示文件名、尺寸/大小（后端补充必要元数据）、明显的选中状态。单击选择，底部“使用所选图片”确认后回填；双击可快捷确认单图。大图预览按需加载，不一次加载所有原图。

多图模式采用复选选择，底部显示已选数量与缩略图，支持取消单项或清空选择；已有字段内容应带入选择状态，避免意外覆盖。上传后默认选中新图，确认后统一回填。

## 上传体验

支持点击和拖拽，提前展示格式和 10MB 限制；提供队列、逐项进度、成功/失败反馈与重试。前端校验只改善体验，服务端校验继续保留。失败不会关闭窗口；上传进行中禁止确认未完成项目。

## 模板和附件

模板以列表为主，展示文件名、相对路径、修改时间；提供搜索、目录面包屑和返回上级。可按名称给常见模板附辅助说明，但保留实际文件名；不运行模板、不在弹窗中渲染模板 PHP/HTML。

附件使用类型图标和列表，展示名称、大小与时间，选择后统一确认。图片、附件、模板按各自允许的根目录浏览，不能通过 UI 或 API 跨越权限边界。

## 检索与规模

目录浏览、名称搜索、按时间/名称排序；文件量较大时增加服务端分页，避免一次返回所有条目。缩略图懒加载，预览图限制显示尺寸；新增元数据或缩略图处理必须有资源上限。

## 实施与验收

1. 先实现统一弹窗和图片单选，提供截图确认视觉方向，再扩展多选、附件和模板模式。
2. 实现上传队列、搜索排序和分页，补齐 API 校验及空目录/加载/失败状态。
3. 验证选择与取消、回填、上传失败重试、多选顺序、键盘操作、小屏，以及目录越界和恶意文件名。分关键节点提交 Git。

首版不包含文件删除、重命名、移动和模板编辑，避免将选择操作扩展为资源管理；这些能力可在后续单独规划。


## 实现记录

- 独立适配器 `admin/js/resource-picker.js`，各后台表单统一加载；前台模板调用方式不变。
- 弹窗桌面最大 960×720，小屏接近全屏。保留后台配色，固定标题和确认区，内容独立滚动。
- 图片支持网格/列表、按需原图预览、明确确认、多选已有值恢复、逐项移除和清空；按选择顺序回填。
- 上传使用 XHR 提供进度，顺序处理队列，失败项可重试；服务端格式、内容、权限和 CSRF 校验继续执行。取消弹窗不回填字段，但已成功上传的文件保留在资源库中；关闭窗口会中止客户端请求，服务端已完成的文件不会自动删除。
- 模板显示实际文件名、相对路径、大小和修改时间，不执行或渲染模板内容。附件使用列表模式。
- 搜索仅限当前目录。列表每页 24 项，接口最多 60 项；单目录扫描超过 10,000 项时提示整理子目录。分页减少响应和渲染量，目录排序仍需扫描目录，超大资源库应另行设计索引。
- 单次最多选择 60 个资源、排队 60 个文件；单文件不超过 10MB。缩略图需管理员登录，只接受图片库内允许格式，最大 2,000 万像素，缩至 320×240 以内，不放大、不保存额外磁盘缓存。损坏或无法解码的图片显示占位图，原图预览按需加载。
- Nginx 新增 `admin/api/thumbnail.php` 白名单，部署时需同步配置并重载。所有脚本、样式和接口均为本地资源。

## 验证结果

- `./bin/dev test`：113 项通过，覆盖新增分页、排序、搜索、特殊文件名编码、参数数组拒绝、缩略图权限/尺寸/目录越界等检查。
- `./bin/dev check`：332 个 PHP 文件，0 语法错误。
- JavaScript 语法检查和 `git diff --check` 通过。
- 真实浏览器验证：后台 iframe 内图片弹窗布局、选中与回填、预览及 Esc 返回、模板搜索和已有选择、取消不回填、真实上传成功、扩展名与内容不符的失败反馈及重试。
- 390px 宽测试页面验证：弹窗内容滚动、确认按钮可见、多图已有值恢复、移除单项和清空回填。附件列表入口正常。
- 测试使用临时本地账号和页面，不保存文章；测试账号、临时页面及本次测试上传文件在结束后清理。截图存放在 Git 已忽略的 `var/verification/`。

未在本轮验证所有手机浏览器、屏幕阅读器和真实弱网下的拖拽上传；这些属于后续兼容性验收范围。
