# 内容页请求与渲染上下文收敛

日期：2026-10-27。代码提交：`13b477a`。本次没有修改前台模板、模板语法或既有伪静态链接格式。

## 改动

- 内容路由把 `project`、`id` 解析为显式的模型名和正整数。模型名长度与数据库 `f_module.project` 的 30 字符字段一致；编号限制在有符号 `INT` 范围内。非法参数返回 400。公共路由守卫原本已拒绝多数格式错误值，这层校验消除了控制器直接调用和边界值上的隐式整数转换。
- 内容路由只读取已启用的自定义内容模型；内置 `single` 仍可访问。系统数据表和已停用模型返回 404。已发布但不存在的记录仍返回 404。
- 旧模板继续在渲染期间通过 `$_GET['classid']` 取得文章所属栏目。模板结束或抛出异常后恢复原请求值；原请求没有该键时移除临时键。
- 回归测试增加非法参数、模型访问、单页、文章阅读次数及渲染上下文恢复的检查。认证码回归测试改用真实的站点认证码，消除了字母 `E` 被当作科学计数法转换时的偶发 PHP 弃用警告。

## 验证

- `./bin/dev check`：340 个 PHP 文件，语法错误为零。
- `./bin/dev test`：488 项 HTTP/数据库回归通过，独立契约测试及隔离数据库导入演练通过；测试输出无 PHP Warning、Deprecated、Notice、Fatal error 或 Parse error。
- 在本地隔离数据副本上访问同一内容页，前后均为 HTTP 200、569050 字节。去除每次请求随机生成的令牌后，仅剩阅读次数从 8 到 9 的一位变化；其余 HTML 相同。隔离副本中的测试请求会增加该记录的阅读次数。
- 未连接生产站点，也未修改生产代码、数据库或配置。维护者留在工作区的 `template/goods_search.html` 未纳入提交。

## 兼容与成本

既有文章和单页地址继续使用原路由。曾依赖内容路由直接读取系统模型或已停用自定义模型的地址现在返回 404，这是有意的访问范围收紧。模型授权需要在每个内容页请求中额外读取一次 `f_module`；本轮未进行可归因的前后耗时基准测试，因此不报告提速或延迟比例。若真实站点的内容页吞吐量显示该查询成为瓶颈，应先测量，再考虑在请求内复用模型元数据。
