# 后台使用指南

后台地址为 `https://你的域名/admin/login.php`。登录需要账号、密码和认证码。认证码是登录凭据的一部分，请与密码一样妥善保管。

## 账号角色

系统提供两种固定角色，权限不能自行拆分配置：

| 后台功能 | 超级管理员 | 编辑 |
| --- | --- | --- |
| 内容：栏目、文章、回收站 | 管理 | 管理 |
| 相关：基础信息、留言查看与回复 | 管理 | 管理 |
| 系统设置、模块和模型、数据库备份与导入、模板编辑 | 管理 | 无权限 |
| 图片和附件上传、站内资源选择 | 可以 | 可以 |
| 创建账号、管理其他账号 | 可以 | 无权限 |

超级管理员账号不能通过账号管理页面删除或停用。超级管理员可以创建超级管理员和编辑账号。编辑人员可修改自己的用户名和密码；账号管理由超级管理员负责。

## 管理栏目与内容

1. 在“内容”中选择模型，再进入栏目或内容列表。
2. 创建内容前，先确认模型字段和目标栏目已经准备好。带必填标记的字段必须填写。
3. 正文使用富文本编辑器，可输入文字、设置格式、插入链接、上传或选择站内图片，也可插入网络图片地址。
4. 保存后从前台检查标题、正文、图片、栏目面包屑和分页显示。模板决定前台具体样式。
5. 删除的内容通常先进入回收站；确认不再需要后再彻底删除。恢复前检查目标栏目仍存在。

## 图片和附件

使用编辑器工具栏或资源选择器上传文件。系统会检查允许的类型、文件大小和图片内容。上传目录禁止执行脚本；不要尝试上传程序文件或可执行内容。

网络图片通过浏览器直接引用远程 HTTP/HTTPS 地址，不会由 FengCMS 服务器下载或转存。若图片来源删除、改地址或禁止外链，网站中的图片也会失效。

## 留言与基础信息

编辑和超级管理员可以查看、回复和管理留言，也可维护“相关”页签里的基础信息。提交修改后，检查前台留言状态及显示内容是否符合预期。

## 模板和系统设置

模板、模型结构、数据库、站点系统设置和账号管理只对超级管理员开放。模板决定页面结构，错误修改可能影响网站显示；修改前先保存模板副本，并在测试站点检查。

## 备份

超级管理员可在数据库管理页面创建备份、管理备份、下载或删除备份，也可导入符合限制的本系统备份。备份文件可能包含用户数据，应限制访问并妥善保管。后台导入适用于规模较小且结构一致的数据；具体限制和恢复流程见[数据库备份与恢复](数据库备份与恢复.md)。

## 账号安全习惯

- 每人使用自己的账号，不共用超级管理员账号。
- 使用独立、难猜的密码；密码和认证码不要放在同一条公开消息中。
- 人员离开后，尽快停用或删除其编辑账号。
- 修改密码或认证凭据后，按页面提示重新登录。

## 特别版历史富文本编辑

本版本使用 KindEditor 4.1.7 编辑正文、自定义富文本和版权；上传、资源选择与图片字段保持现有实现。

编辑区在载入前执行安全检查。已有文章的正文未改动时，只修改标题等其他字段并保存会保留原始正文；修改正文后仍执行服务端清洗。“查看原始 HTML”可以查看本次打开时的原文，“编辑 HTML / 转存内嵌图片”可编辑源码、检查并预览后应用，“恢复本次打开的原文”会放弃当前富文本修改。

含 Base64 图片的旧正文需先转存图片再编辑；本特别版不运行 Markdown 转换或自动重排。取消预览后已上传文件会留在资源库。载入失败的已有正文可保留原文并只保存其他字段；新建内容必须先处理失败的富文本字段。

具体流程、格式支持和兼容限制见[客户兼容版说明](客户兼容版说明.md)。此前通用版本的“优化历史富文本”操作说明不适用于本分支。

## 单张图片与多张图片字段

后台图片字段使用正方形缩略图。单图为空时点击“＋”选择；已有图片可点击“更换”，或点击“×”移除引用。多图在末尾显示“＋ 添加图片”，打开资源选择器后会带入已有图片，可继续选择并确认，也可切到上传页上传新图。取消选择不会改变当前字段。

点击任意缩略图可打开大图预览。多图可使用左右按钮或键盘方向键切换；点击关闭按钮、背景或按 Esc 关闭。图片加载失败时显示占位，原地址仍保留，便于重新选择。

多图可拖动排序，也可使用每张图片下方的左右箭头。移除或调整顺序后，须保存当前内容才会写入数据库；“×”仅移除当前内容中的引用，不会删除资源库文件。字段自身的必填和长度限制继续适用。后台单次资源选择仍受原有数量限制，历史超限内容不会因打开页面而自动截断。
