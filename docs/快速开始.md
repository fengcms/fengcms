# 新手快速开始

## 先判断你要做什么

- **安装一个全新网站**：准备一个空数据库，按[新站安装指南](安装指南.md)操作。
- **升级已经运行的网站**：不要运行首次安装向导。先按[已有网站升级指南](已有网站升级指南.md)准备备份和副本。
- **已经进入后台**：从[后台使用指南](后台使用指南.md)了解账号角色、栏目、内容和资源管理。
- **遇到配置或页面问题**：查看[配置与服务器设置](配置与服务器设置.md)和[常见问题](常见问题.md)。

## 新站安装前准备

1. 下载 GitHub Releases 中的正式版压缩包及 SHA-256 校验文件。确认压缩包校验通过后再解压和上传。
2. 准备支持 PHP 8.3 或 8.4 的网站空间，并启用 `mysqli`、`mbstring`、`gd`、`fileinfo`、`json` 扩展。
3. 在主机面板创建 MySQL 或 MariaDB 数据库和专用用户。安装器不会替你创建数据库。
4. 为网站配置 HTTPS，并确认空间允许 PHP 写入站点配置文件和 CMS 指定的数据目录。

## 安装后的第一步

完成安装后，确认一次性安装授权文件已删除；登录后台后检查首页、栏目、内容、图片上传和数据库备份。请把数据库凭证、管理员密码、后台认证码及私有配置保存在安全位置，不要发到公开论坛或提交到 Git。

FengCMS 不会在后台自动下载或安装更新。新版本从 [GitHub Releases](https://github.com/fengcms/fengcms/releases) 获取；升级前始终先阅读对应版本说明，并在网站副本中验证。
