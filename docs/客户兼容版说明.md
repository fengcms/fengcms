# KindEditor 4.1.7 客户兼容版

本分支用于需要继续编辑历史 HTML 的存量站点。后台的正文、自定义富文本和版权字段使用 KindEditor 4.1.7；图片字段、缩略图、相册排序、资源选择器、上传和文件管理继续使用当前 FengCMS 的实现。栏目介绍仍为原来的普通文本字段。

模板写法、前台路由、HTML 存储方式和数据库结构保持不变。仅打开文章、修改标题等其他字段后保存，不会重新整理未修改的正文。新建或修改富文本时仍执行服务端安全清洗。

## 编辑历史正文

- 编辑区载入前执行安全检查。不能安全载入时，保留原始 HTML；已有文章可以只修改其他字段。
- “查看原始 HTML”显示本次打开时的原文快照。
- “编辑 HTML / 转存内嵌图片”提供源码编辑、安全检查和预览；确认后应用到编辑区，保存文章后才写入数据库。
- “恢复本次打开的原文”放弃当前富文本修改。已经保存并重新打开的文章，以重新打开时的内容为原文。
- Base64 图片通过现有上传接口转存，不执行 Markdown 转换或自动重排。粘贴的内嵌图片可先转存、预览，再插入当前选区。
- 取消预览不会删除已经上传的文件；未使用的文件按站点现有资源管理方式处理。
- 图片和附件工具栏按钮打开现有资源选择器。网络图片由浏览器直接引用，不经过服务器下载。

安全清洗会移除脚本、事件属性、危险地址、嵌入页面和未允许的样式。常用旧式字体、字号、颜色、行距、缩进、表格边框、合并单元格及图片尺寸予以保留；无法保证任意历史 HTML 修改后逐字节不变。正式使用前，应以本站有代表性的历史文章检查编辑、保存、重新打开和前台显示。

KindEditor 4.1.7 是历史依赖，本版本只使用其本地静态编辑功能，未恢复旧版 PHP 上传、文件管理、Flash 或远程地图插件。后台仍面向现代浏览器，不提供旧 IE 支持。更新时请使用本分支对应的整套代码，避免只替换编辑器脚本而遗漏安全清洗和适配文件。
