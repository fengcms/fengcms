# 数据库备份与恢复

## 后台数据库备份

超级管理员在“系统 → 数据库管理”创建备份、管理备份并下载文件。备份可能包含账号、留言和站点内容，下载后应放在受控位置，不要保存在公开网站目录或发送到公开工单。

后台数据库备份只包含数据库，不包含网站源码、上传文件、私有配置或运行配置。做整站迁移或升级时，这些文件必须单独备份。

## 后台导入适用范围

后台导入适用于数据量较小、来源可信且目标站点结构完全一致的恢复场景。目前上传上限为 **8 MB 或 10,000 条记录**。大数据量、表结构不同、跨版本迁移或整站搬迁，建议使用主机面板或数据库客户端在独立副本操作。

导入只接受 FengCMS 生成的受限备份数据，不会把上传文件中的 SQL 命令直接交给数据库执行。导入前会检查目标结构，并自动备份当前数据库；预检或自动备份失败时，不会开始替换数据。确认导入前请仔细核对目标数据库、表前缀和结构。

## 导入步骤

1. 先创建并下载一份当前数据库备份，另外备份上传文件与私有配置。
2. 在“数据库管理 → 备份管理”中选择本系统生成的备份，或上传本系统的备份文件。
3. 点击预览，确认数据库对象、记录数量及表结构检查结果。
4. 确认网站处于允许导入的维护窗口，再执行导入。导入期间系统会暂停新的 CMS 写入。
5. 完成后检查文章、栏目、留言、账号和首页。导入前自动备份可用于回退。

## 中断后的处理

若数据库连接在导入过程中中断，系统可能暂停新的内容、结构、附件写入和新的备份/导入预览。重新登录后台，在导入页面使用“核对并恢复中断导入”入口。按提示完成核对后，再重新预览需要导入的备份。

如果系统提示数据已变化、结构状态不完整或不能安全恢复，请不要删除恢复记录、手动改表名或继续写入。先停止站点写入，在独立副本保全并比较当前表、旧表与备份，再由熟悉数据库的维护人员决定如何恢复。

后台导入屏障只协调 FengCMS 自身写入；独立插件、外部脚本或数据库客户端不受它控制。导入前要单独暂停这些写入来源。

## 恢复整站

整站恢复必须使用相互匹配的代码、数据库、上传文件、私有配置和运行配置。先恢复到隔离副本，确认后台登录、代表性内容、图片和模板可用，再安排正式切换。版本升级和回退步骤见[已有网站升级指南](已有网站升级指南.md)。
