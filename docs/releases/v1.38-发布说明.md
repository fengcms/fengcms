# FengCMS v1.38

v1.38 主要完善历史富文本编辑体验、后台图片字段和内容预览，并首次提供 v1.37 → v1.38 增补升级包。保留原模板调用语法、HTML 内容存储和既有图片字段格式。

## 主要更新

- **历史正文主动优化**：编辑器工具栏提供优化历史富文本、查看原始 HTML、撤销本次优化。确认后使用本地托管的 Turndown + GFM 和 markdown-it 转换，服务端清洗并预览，再由编辑人员应用、保存。不会打开文章就自动重排。
- **历史正文保护**：隔离编辑器初始化失败，保留原文与恢复入口；转换过程中检查文字、图片和可见链接，无法完整保留时停止应用。改善中文相邻强调及图片超链接往返。
- **Base64 图片转存**：优化前将允许格式的内嵌图片经现有认证上传接口安全转为站内图片，检查实际格式、尺寸和可解码性，支持同页去重与重试。未完成转存时阻止保存，避免清洗静默丢图。取消优化后已上传文件保留在资源库。
- **图片字段界面**：单图、多图使用正方形缩略图，支持选择、更换、移除、大图预览、多图追加、拖动及按钮排序。保留原字段存储方式，移除只解除内容引用。
- **内容预览链接**：修复动态 URL 模式下后台内容标题和栏目预览多加斜杠，导致浏览器出现 about:blank#blocked 的问题。
- **只读部署兼容**：修复保存预检的 HTML Purifier lexer 默认磁盘缓存引发的权限警告，不修改第三方目录权限、不屏蔽 PHP 诊断。

## 下载选择

- 新站、完整部署或更早版本升级：`fengcms-v1.38.zip`。
- 已完整运行正式 v1.37：`fengcms-v1.37-to-v1.38.zip`，需先核对基准及定制差异。
- `SHA256SUMS.txt` 包含上述两个 ZIP 的 SHA-256；另外保留每个包独立的 `.sha256` 文件。

GitHub 自动生成的 Source code 压缩包不是专用增补包。详细操作见[已有网站升级指南](../已有网站升级指南.md)。

## v1.37 升级注意事项

1. 完整备份代码、数据库、上传与私有/运行配置，先在独立副本验证；不要运行首次安装向导。
2. 从本次增补包基准的正式 v1.37 升级，无新增数据库结构迁移。更早版本仍须执行其升级要求。
3. 本轮修改了后台模板。前台模板语法保持不变，但修改过后台模板或核心代码的站点应先合并。
4. **新增 `/admin/api/richtext.php` 入口**：使用项目 PHP 白名单的 Apache、Nginx、IIS 站点，需要在原有上传/资源/缩略图入口后增加 richtext。增补包将服务器配置单独放在“服务器配置参考”，不能直接覆盖实际服务器的定制配置。Nginx 需更新生效站点配置并检查、加载。
5. 清除前后台模板缓存并强制刷新浏览器；验证登录、资源选择和上传、图片字段、富文本预览/应用/撤销及本站前台功能。

历史富文本优化可能改变字体、颜色、对齐等排版，复杂表格、视频等内容不保证自动转换。每个富文本字段单独处理，先检查预览；已经在过去保存时丢失的内容需从备份恢复。详见[后台使用指南](../后台使用指南.md)。

## 环境与质量检查

继续支持 PHP 8.3、8.4、8.5，本轮由 GitHub CI 对 PHP 8.4/8.5 执行语法、HTTP/数据库和 PHP 诊断门槛检查。发布以最终提交所有 CI 项目通过为前提。PHP 8.3 沿用此前兼容范围，本轮未单独重复完整测试。IIS 配置尚未在 Windows/IIS 实机验证。

新增增补包工具会从正式标签的发布文件树生成差异，保留文件权限与第三方许可证，分离服务器配置，并在打包时模拟新增、覆盖、删除后核对完整目标发布树。升级包不提供自动在线安装器。
