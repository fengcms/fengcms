# FengCMS v1.36

本版为普通 PHP 虚拟主机的新站点提供安全的网页首次安装流程。已有站点请继续按备份、迁移和验收步骤手动升级，不要运行首次安装向导。

## 主要变化

- 通过站长在文件管理器或 SFTP 中放置的一次性随机密钥开启安装；表单需要 HTTPS、会话及 CSRF 校验。
- 安装前核对数据库名称、表前缀、将创建的表和视图。若目标前缀已有对象则拒绝安装；安装 SQL 不含删表语句或可登录的默认密码。
- 使用 `password_hash()` 初始化管理员；数据库凭证和随机应用密钥写入独立私有配置，安装成功后锁定入口。
- Apache `.htaccess` 与 Nginx 示例规则限制安装内部文件、私有配置和上传脚本的访问。旧网页安装代码已移除，本地 Docker 开发仍使用 `./bin/dev up` 初始化。

## 安装与兼容范围

按[共享虚拟主机首次安装说明](../INSTALLATION.md)准备 HTTPS、数据库、PHP 扩展和目录权限。安装器要求 PHP 8.3 或 8.4；数据库由主机面板预先创建，用户需要建表、建视图及写入权限。禁止把站点目录设成 777，也不要提交 `config.local.php` 或 `install/authorize.php`。

已在隔离环境验证：PHP 8.4.27 + MySQL 8.4.11（Nginx、Apache），PHP 8.3.36 + MariaDB 10.11.19（Apache）的首次安装、首页和后台登录。本地 PHP 8.4/MySQL 8.4 的 280 项业务回归及 9 项驱动回归通过。LiteSpeed、真实共享主机面板，以及 PHP 8.3/MariaDB 组合下的全部业务流程尚未实测。MyISAM 建表失败不能整体回滚，需核查已创建对象后再处理。

发布附件 `fengcms-v1.36.zip` 是标签对应的完整源码快照，`fengcms-v1.36.sha256` 用于完整性校验。包内包含 `.htaccess` 和安装示例，但不包含数据库、上传文件、私有配置或安装密钥。
