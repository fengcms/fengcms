# FengCMS v1.37

v1.37 汇集了安全加固、后台权限、数据一致性、性能和旧站兼容方面的更新。已有网站升级前，请先完整备份，并在独立副本中完成数据库迁移和业务验收；不要运行首次安装向导。

## 主要更新

- **后台账号与角色**：增加超级管理员和编辑两种固定角色。编辑可维护“内容”和“相关”，系统设置、模型、模板、数据库与账号管理仅供超级管理员使用。
- **数据库备份与导入**：增加备份管理、下载和恢复保护；导入保留预览、结构核对、自动备份及异常中断恢复，只接受 FengCMS 受限备份数据，不执行上传 SQL 文件中的任意命令。后台导入适合小型、结构一致的数据。
- **模型与字段维护**：模型导入改用受限格式，模型及自定义字段操作增加失败续做和并发保护。
- **内容与留言**：加强文章创建、编辑、回收站、栏目归属、留言回复和重复提交保护；保存失败时保留编辑表单并显示错误。
- **上传与资源选择**：检查图片实际内容，修复多图引用丢失和重复上传恢复问题；继续禁止上传目录执行脚本。
- **PHP 兼容**：安装器支持 PHP 8.3、8.4、8.5；修复 PHP 8.5 下图片资源释放函数的弃用诊断，并将 PHP 8.4/8.5 纳入持续集成回归。
- **前台性能与兼容**：改进栏目导航、相关文章和搜索分页查询，修复栏目路由、分页、标签及焦点图等问题。
- **配置与服务器**：更新 IIS `web.config` 路由和访问限制，补充中文安装、使用、升级、配置及备份指南。IIS 规则仍需在目标 Windows/IIS 环境验证。

## 已有网站升级

1. 备份源码、数据库、上传文件、私有配置和运行配置，并在隔离副本确认可恢复。
2. 在副本部署 v1.37 代码和站点定制文件，检查 PHP 与数据库连接配置。
3. 使用目标站点的私有配置，通过 PHP CLI 执行 `php tools/migrate.php`。迁移会修改数据库，包含后台角色、内容写入状态、模型结构恢复、上传重试、留言版本及栏目索引等变更；执行前必须先备份。重复用户名等异常需先处理。
4. 验证超级管理员与编辑权限、栏目和文章、回收站、留言、上传、模板、搜索、备份与恢复，以及本站实际使用的定制功能。
5. 副本验收通过后再安排正式停写切换。详细步骤见[已有网站升级指南](../已有网站升级指南.md)。

若主机没有 PHP CLI，不要把迁移命令暴露为公开网页入口。先联系主机商提供终端或协助执行，并在副本确认迁移结果；无法安全完成数据库迁移时，暂缓升级。

## 环境与验证

PHP 8.4.27 与 PHP 8.5.12 均通过完整 PHP 语法检查和 HTTP/数据库回归；PHP 8.5.12 还通过隔离的新站网页安装、后台登录及 PHP 诊断检查。MySQL 8.4、Nginx 与 PHP-FPM 用于本地容器验证。CI 分别检查 PHP 8.4、8.5。PHP 8.3 属于安装器支持范围，并在 v1.36 的 PHP 8.3.36 环境完成过新站安装及后台登录验证。Apache/Nginx 配置已在项目验证范围内；IIS 配置已经静态检查，尚未在 Windows/IIS 实机验证。存量站点的定制环境仍需逐站在副本确认。
