# FengCMS v1.37-kindeditor 特别版

本版本面向需要使用 KindEditor 4.1.7 维护历史 HTML 的站点，发布自独立客户兼容分支。它以当前 master 修复基线开发，包含正式 v1.37 之后的相关改进；版本名称用于识别特别分支，不表示仅将 v1.37 的编辑器文件替换。通用版继续独立维护，本版本不设为 GitHub Latest。

## 主要变化

- 正文、自定义富文本和版权字段使用本地托管的 KindEditor 4.1.7，保留第三方许可证与官方文件摘要。
- 图片上传、附件、资源选择器、单图/多图缩略图、预览和排序继续使用当前实现；不恢复旧 PHP 上传、旧文件管理或 Flash 插件。
- 原文先安全清洗再载入编辑区；只改标题等其他字段时，未改动的富文本按原始字节保留。修改正文时仍执行服务端 HTML Purifier 清洗。
- 支持原始 HTML 查看、安全源码编辑、预览与撤销，以及通过现有上传接口转存 Base64 图片；不执行 Markdown 转换或自动重排。
- 在安全白名单内兼容旧式字体、字号、行距、缩进、表格、合并单元格、图片尺寸及链接图片；保留认证、角色、CSRF 和上传校验。
- 包含基线中的图片字段改进、内容预览链接修复，以及后续内容可见性、模型状态隔离、标签查询、图片解码内存预算和 PHP 8.5 兼容修复。

前台模板文件、模板调用语法、URL 契约和 HTML 存储方式保持不变。栏目介绍仍是原有普通文本字段。已修改正文可能被浏览器和清洗器规范化，不能保证任意旧 HTML 修改后逐字节或逐像素不变；应使用本站代表性内容验收。

## 下载

- 完整包：`fengcms-v1.37-kindeditor.zip`。
- **正式 v1.37 专用升级补丁**：`fengcms-v1.37-to-v1.37-kindeditor.zip`。
- 两个 ZIP 的独立 `.sha256` 文件，以及汇总校验文件 `SHA256SUMS.txt`。

补丁来自 GitHub 已发布的 v1.37 完整包对应标签，按完整发布文件树生成。打包验证会模拟所有新增、修改和删除，并核对字节及权限与完整目标包一致。GitHub 自动生成的 Source code 压缩包不是升级补丁。

## 从 v1.37 升级

1. 备份代码、数据库、上传、私有配置和运行配置，在独立副本先验证可恢复。已有站点不要运行首次安装向导。
2. 核对正式 v1.37 基准及补丁中的 `文件校验清单.json`。如本站同名文件与 before_sha256 不同，先比较和合并定制，不要盲目覆盖。
3. 暂停后台写入，将补丁“网站文件”目录里的内容按相对路径放入网站根目录；按清单处理需要删除的原版文件。补丁不包含数据库、用户上传或私有配置。
4. **必须允许 `/admin/api/richtext.php`**：这是编辑区安全载入、粘贴和预览所需的新入口。使用 PHP 入口白名单的 Apache/Nginx/IIS 站点须加入该路径，并保留其他 PHP 禁止规则。服务器配置在“服务器配置参考”中单独提供，需人工合并到实际生效配置，不可直接覆盖自己的域名、证书或 PHP-FPM 设置。
5. 从完整正式 v1.37 升级到本版本，**无新增数据库结构迁移，不必运行迁移或安装器**。更早版本、未完成 v1.37 迁移的站点仍须按相应升级指南处理；本补丁不适用于 v1.38 或其他分支。
6. 清除前后台模板缓存，强制刷新浏览器，确认后台版本为 `v1.37-kindeditor`。检查只改标题保存、修改正文后重开、表格与图片链接、Base64 转存、全屏、上传与资源选择、角色权限及前台定制功能。通过后再安排正式切换。

失败时停止写入，恢复同一备份点的代码、数据库、上传和配置。只回退编辑器脚本不会恢复已保存改变的正文。

## 验证范围

本地 PHP 8.4.27、8.5.12 均已通过完整回归，各含 659 项 HTTP 检查，语法检查 370 个 PHP 文件无失败，本轮日志无 PHP 诊断。真实 Chrome 验证覆盖后台 iframe、全屏、资源选择/取消、图片与附件上传、历史 HTML 保存重开及前台输出、多富文本字段、版权和内嵌图片处理。发布前还要求最终提交的 GitHub static 与 PHP 8.4/8.5 integration 全部通过。

PHP 8.3 沿用项目兼容范围，本轮未重新执行完整回归；IIS 未在 Windows 实机验收。KindEditor 4.1.7 为历史组件，本分支仍面向现代浏览器，不提供旧 IE 支持。合成样本和开发环境验证不能替代客户实际历史文章及目标服务器验收。
