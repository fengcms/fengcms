# FengCMS v1.35

这是停用旧官网和论坛后的首个 GitHub 正式版。后续版本、下载文件与更新说明统一使用 GitHub Releases。

## 主要变化

- 更新安全基础：容器化本地开发环境、PHP 8.4 兼容修复、登录与会话保护、CSRF、参数和路径校验、上传校验、富文本服务端清洗。
- 后台改用 MIT 许可的 wangEditor 5，支持本地与网络图片、资源选择；修复文章编辑、模板管理、自定义模型字段、回收站、留言和搜索等问题。
- 后台首页可查询 GitHub 最新正式版本并链接到发布记录；不提供在线更新。废弃旧官网版本接口，更新入口改为 GitHub。
- FengCMS 自有代码和文档采用 MIT License；随附第三方组件保留各自许可证。

## 环境与升级

本版已在本地 Docker 环境的 PHP 8.4、MySQL 8.4、Nginx 上验证。既有站点可能使用不同版本、插件和定制模板，不能据此推断可以直接覆盖升级。升级前请备份代码、数据库、上传与配置，在站点副本中验证功能和兼容性。数据库有 MyISAM 表时，备份需保证一致性。

发布附件 `fengcms-v1.35.zip` 是标签对应的完整源码快照；用同页的 `fengcms-v1.35.sha256` 检查下载完整性。压缩包不包含站点数据、私有配置或上传文件。旧版迁移与本地运行细节见 `docs/SECURITY_UPGRADE.md`、`docs/LOCAL_DEVELOPMENT.md`。
