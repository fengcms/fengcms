# 共享主机网页安装方案

> 实施状态（2026-10-26）：已完成非覆盖式安装数据、私有配置、一次性授权的网页向导及 Apache/Nginx 访问规则，并准备随 v1.36 发布。在隔离环境通过 PHP 8.4/MySQL 8.4 与 PHP 8.3/MariaDB 10.11 的首次安装验证；详细版本和未验证范围见[安装文档](INSTALLATION.md)。本文件保留原规划和验收范围，下面的“旧向导”表述反映规划时的状态。

## 目标与边界

让使用普通 PHP 虚拟主机的站长上传发布包后，通过浏览器完成**首次安装**，不依赖 SSH、Docker、Composer 或数据库命令行。当前 `./bin/dev up` 继续服务本地开发；已安装站点的版本升级不由安装向导处理。旧 `install/` 向导仍保持禁用，不能通过删除 404 规则直接复用。

第一批支持范围以实际测试为准：优先 PHP 8.3、8.4，`mysqli`、`mbstring`、`gd`、`fileinfo` 等所需扩展，以及常见 MySQL/MariaDB 共享主机。当前项目只在 PHP 8.4 + MySQL 8.4 + Nginx 本地环境验证过；在完成对应矩阵测试前，不宣称其他组合已受支持。PHP 旧版本可以收到明确的环境不兼容提示，但安装器不能令旧版 PHP 运行当前 CMS。

## 站长操作流程

1. 在主机面板创建数据库和数据库用户，启用 HTTPS，上传正式版源码。主机应允许 PHP 用户写入指定配置和运行目录，不需要 `777` 权限。
2. 站长通过文件管理器或 SFTP 按模板创建 `install/authorize.php`，填入自己生成的高强度一次性安装密钥。没有该文件时，安装页只显示操作说明，不能修改数据库或配置。这证明操作者拥有站点文件的写入权限，避免第一个访客抢先创建管理员。
3. 访问 `/install/index.php`，输入安装密钥，完成环境、目录权限、HTTPS 和数据库连通性检查。密钥只通过 POST 发送；验证后轮换会话，并为后续表单使用 CSRF 令牌。
4. 填写数据库连接、未使用的表前缀、管理员用户名和自选强密码。页面在提交前明确显示将创建的对象及目标库名，但绝不回显密码。所有敏感字段只通过 HTTPS + POST 传送，响应禁止缓存。
5. 安装器确认目标前缀没有任何现有表或视图，创建数据库对象、写入 `password_hash()` 生成的管理员密码，生成随机应用密钥和后台认证码，最后原子发布私有配置。成功页只显示登录入口和必要的认证码；建议站长保存后删除授权文件。
6. 私有配置或安装完成标记存在时，所有安装写操作一律拒绝。重新安装必须由站长在主机面板中明确备份并手工清理目标资源，不能由网页上的“重装”按钮触发。

## 实现约束

- **共享主机可用性**：安装入口保持最小依赖与清晰的中文错误提示。若主机禁止 PHP 写入配置目录，停止安装并引导站长通过主机面板调整文件归属或最小必要权限；不能提示用户开放 `777`。Apache/LiteSpeed 使用随包 `.htaccess`，Nginx 提供等效示例规则；只公开安装入口和必要静态资源。
- **数据库安全**：使用 `mysqli`；严格校验库名和表前缀；只连接已由面板创建的数据库，不要求 `CREATE DATABASE` 权限。安装 SQL 不包含 `DROP`，不内置可登录的默认密码，也不覆盖已有前缀。执行失败立即停止并报告已创建对象，避免把 MyISAM 导入误称为可事务回滚。
- **配置安全**：数据库密码只进入 POST 请求和服务端私有配置，不进 URL、页面、日志或 Git。配置值作为数据编码，不通过字符串替换拼接 PHP 源码；临时文件同目录创建并原子重命名。保留现有环境变量配置路径，避免破坏容器部署。
- **入口安全**：安装授权密钥使用 `hash_equals()` 比较；表单使用会话、CSRF 和 POST。设置合理的输入长度、安装尝试限速和超时。安装过程不加载远程脚本或统计服务。完成后锁定，防止在已有站点上重跑。
- **部署检查**：验证私有配置不能被 Web 下载，上传目录不能执行 PHP，安装目录的其他文件不能直接访问。安装器若无法确认所需的权限与 Web 服务器限制，应停下并给出配置指引。

## 实施与验收顺序

1. 整理安装数据和私有配置：移除旧 SQL 的覆盖语句与默认口令，提取与开发 bootstrap 共用的初始化逻辑，补上缺少的安全表及配置读取；先跑现有回归。
2. 重写网页向导与 Apache/Nginx 访问规则：实现一次性授权、环境检查、数据库和管理员设置、安装锁；旧 `mysql_*` 和远程脚本入口删除或保持不可访问。
3. 在独立数据库和虚拟主机式环境中完成浏览器实测：成功安装后登录、首页/后台、上传与模板操作；验证错误密钥、缺失 CSRF、GET 提交、非 HTTPS、已有前缀、部分 SQL 失败、重复安装、不可写配置、直连私有文件均安全失败。
4. 对 PHP 8.3/8.4 与选定的 MySQL/MariaDB 版本分别完成实测，再写明实际支持矩阵、主机面板安装步骤和故障排查；发布新版本，不修改既有 `v1.35` 标签。

各关键节点分别提交 Git。验收前保留当前对 `/install/` 的 404；实现完成后只开放新的安装入口，现有 Docker 环境仍可选择 CLI 开发初始化方式。
